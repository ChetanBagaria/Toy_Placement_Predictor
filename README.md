# Placement Predictor

A basic machine learning model that predicts student placement outcomes using **Logistic Regression** trained on a toy placement dataset.

## Features

- Exploratory Data Analysis (EDA)
- Data visualization using plots and graphs
- Feature scaling
- Logistic Regression model training
- Achieved **90% accuracy** on the dataset
- Visualized the model's decision boundary to analyze the influence of CGPA and IQ on placement predictions

## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Key Observation

The decision boundary suggests that **CGPA has a stronger influence on placement predictions than IQ** in the toy dataset.

## Note

This is a beginner-level machine learning project created for learning and experimentation. The reported accuracy applies to the dataset and evaluation setup used in this project.
